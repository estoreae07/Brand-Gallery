Product catalogue website
=========================

This site is generated from Inventory Data 5.xlsx. It includes 392 products and preserves the spreadsheet's Product ID values.

To publish free with GitHub Pages:
1. Create a free GitHub account at github.com.
2. Create a new public repository, for example product-catalog.
3. Upload every file in this folder (not the folder itself).
4. In the repository, open Settings > Pages. Under Build and deployment, select Deploy from a branch, then choose main / (root), and Save.
5. GitHub will display your free HTTPS address, usually https://YOUR-USERNAME.github.io/product-catalog/

There is no hosting fee or yearly website-builder fee. A custom domain is optional and may have its own charge.

To update products later, replace products.js by running this same build process on an updated spreadsheet, then upload the changed products.js file to GitHub.

Images and destination links were not present in the spreadsheet. The website intentionally uses initials-based product artwork until those fields are supplied.
